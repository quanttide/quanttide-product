# 量潮产品云

帮草台班子打大仗的产品研发工具。

## 你是不是也这样

你一周上线了好几个产品。每一个都赶着上线，上线之后才发现每一个都粗糙。

你知道需要打磨，但不知道先打磨哪个。20多个产品等着你，你一个人扛着，感觉永远打磨不完。

你不是不想做好。是产品太多，你分不出精力，也不知道怎么把它们理清楚。

## 负责人真正难的不是做事

是**看不清全局**。

你同时管着好几个产品，每个都有一堆事情。你想看全局，但每次都陷在细节里。

产品团队的成员也一样。如果你只是埋头做自己那一块，不知道这个产品在整个体系里处于什么位置、不知道别人的进展如何——你做的决定可能是局部最优，但整体不一定对。

## 产品云帮你做一件事

**让你看清楚全局，也让团队里的每个人都建立这个视角。**

- 你管着好几个产品，产品云帮你把所有产品的状态放在一张图里
- 你不知道先打磨哪个，产品云帮你看清每个产品的成熟度和优先级
- 团队成员不知道全局，产品云让他们也能看到完整的产品地图

## 这套方法从哪来

不是凭空造的。是量潮自己用了很久的方法——怎么管理多个产品、怎么做全局取舍、怎么让团队建立统一视角。

底层是量潮第二大脑：所有产品的需求、地图、版本记录都沉淀在一个地方，不会丢、不会过时、不会"又重新想一遍"。

## 你可以先试试

产品云还在建设中。如果你也是一个人扛着多个产品的负责人，可以先用起来，让团队也建立起全局视角。
