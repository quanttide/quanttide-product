# 量潮产品云

帮草台班子打大仗的产品研发工具。

## 你是不是也这样

你一周上线了好几个产品。每一个都赶着上线，上线之后才发现每一个都粗糙。

你想打磨，但产品太多，你连有哪些产品都记不清。哪些做了、哪些没做、哪些需要打磨——全在你脑子里，没有一个地方能看清楚。

## 产品云先帮你做一件事

**把这些产品记下来。**

你有多少产品、每个产品做到哪了、谁在负责——这些事情，先记在一个地方。

这不是什么高级的工具。就是一个有结构的台账。但记了，比不记强得多了。

## 这套方法从哪来

量潮自己先用起来了。所有产品的需求、版本、状态都沉淀在一个地方，不会丢、不会过时、不会"又重新想一遍"。

底层是量潮第二大脑：文档、需求、版本记录都沉淀在一个地方。

## 你可以先试试

产品云还在建设中。如果你也有好几个产品散落在各处，可以先用起来，把它们记下来。
