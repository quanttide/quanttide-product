# 量潮产品云

帮草台班子打大仗的产品研发工具。

## 你是不是也觉得

事情永远理不清。你脑子里知道大概要做一个什么东西，但就是说不清楚。

每次和开发聊，都说不清楚"到底要做成什么样"，最后做出来的东西和你想的不一样，你也不知道为什么。

你想做好的。你只是不知道怎么把脑子里的东西变成别人能理解的东西。

## 小团队最大的难处

不是能力不够，是**一个人要当好几个人用**。

你要想方向、要写需求、要盯进度、要验收，甚至还要写文档——没有人帮你把这些事情分清楚。

大团队有产品经理、有项目经理、有架构师。你只有你自己。

## 产品云帮你做一件事

**把你脑子里模糊的东西，变成清楚的东西。**

- 你脑子里有一堆零散的想法——产品云帮你画成一张地图
- 你说不清楚"到底要做成什么样"——产品云帮你想清楚、写下来
- 你不知道做到哪了——产品云帮你看见

## 这套方法从哪来

不是凭空造的。是量潮自己用了很久的方法——怎么把一件事想清楚，怎么把需求写明白，怎么让团队知道在做什么。

底层是量潮第二大脑：所有的东西都沉淀在一个地方，不会丢、不会过时、不会"又重新想一遍"。
